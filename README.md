# Retain Target

Crew planning board. The chart stays empty until you load a TimeTarget CSV.

The published mock is [bthompson91.github.io/Retain-Target](https://bthompson91.github.io/Retain-Target/). GitHub Pages serves the `docs/` folder from `main`.

Departments fold with +. Zoom is Day, 6h, or Hour. Today is blue. Other days and hours alternate grey.

Each shift shows the employee, then function and role.

## Shift outline

- Confirmed: solid black
- Unconfirmed: dotted black
- Unassigned, or a name that starts with a number: dotted red

## Role colour

| Role | Colour |
| --- | --- |
| Audio | Red |
| Vision, DES | Green |
| Lighting | Blue |
| Warehouse, driver, loader | Purple |
| Technical director | Grey |
| Camera | Teal |
| AV | Light yellow |
| Anything else | White |
